Status pills

Status is load-bearing across the platform, so every pill carries three redundant signals — color, a written label, and a distinct shape glyph — never color alone. Shapes encode meaning: ● done/positive, ○ waiting, ◐ in progress, ■ negative/closed, ▬ moved.
